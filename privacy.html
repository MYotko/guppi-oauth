GUPPI privacy policy

Last updated November 11, 2026.

GUPPI is a private household assistant run by its owner on the owner's own computers. It is not offered to the public.

What it accesses

With the owner's permission, GUPPI uses the Google Tasks API to read and write tasks on the owner's own task lists. It requests no other Google data.

How the data is used and kept

Task data is used only to carry out the owner's requests, such as adding an item to a list or reading a list back. The sign-in credential and any task data are kept on the owner's own computers. Nothing is sold, shared with third parties, or used for advertising.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, after which GUPPI can no longer reach Google Tasks.
